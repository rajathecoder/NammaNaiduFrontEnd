## 2024-05-24 - Removed Hardcoded Configuration Secrets
**Vulnerability:** Several sensitive keys and identifiers, such as Razorpay keys and Firebase configuration settings, were utilizing inline hardcoded strings as fallbacks when environment variables were absent. Given that Vite statically embeds these 'import.meta.env' instances during the build process, if the environment variables were missing, the inline fallbacks would be directly injected into the client-side JavaScript bundles, exposing secrets and configuration details publicly.
**Learning:** In Vite, 'import.meta.env' values are statically replaced during build. If an environment variable is missing and a hardcoded fallback string is provided inline (e.g., 'import.meta.env.KEY || "secret"'), that secret becomes directly readable in the minified frontend bundle.
**Prevention:** Always implement explicit runtime validation functions that check for the presence of required environment variables independently and throw a generic error if they are missing. Avoid inline fallback strings for sensitive configuration data within the Vite context.
