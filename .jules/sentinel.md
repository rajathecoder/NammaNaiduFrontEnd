## 2025-02-12 - CMS Content XSS Vulnerability\n**Vulnerability:** CMS page content (HTML) was being injected into the DOM directly using `dangerouslySetInnerHTML` without any sanitization in public `ContentPage.tsx`, `ContactUs.tsx`, and admin `CMSPage.tsx`.\n**Learning:** In a CMS-driven system where administrators or content managers can create arbitrary HTML, trusting the data base output blindly is dangerous. A compromised admin account or an injection vulnerability on the save side could lead to stored XSS for all end users.\n**Prevention:** Always use `DOMPurify` (via a centralized `sanitizeHTML` utility) when using React's `dangerouslySetInnerHTML`, even if the source is considered internal/trusted.
