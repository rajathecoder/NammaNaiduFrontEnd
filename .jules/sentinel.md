## 2024-05-24 - Custom DOMParser XSS Sanitization Fallback\n**Vulnerability:** CMS page content rendered via dangerouslySetInnerHTML without sanitization, leading to XSS.\n**Learning:** In the absence of approved security libraries like DOMPurify, a custom DOMParser fallback must be used, which must strictly handle javascript: URIs with null bytes and control characters (e.g., `\ufffd`).\n**Prevention:** Always use established sanitization libraries when possible, or strictly strip script tags and javascript protocol hrefs if falling back to custom sanitizers.
