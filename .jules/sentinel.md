## 2025-02-14 - Inline Fallbacks Expose Secrets via Vite Static Replacement
**Vulnerability:** Hardcoded fallback values for secrets (e.g., `import.meta.env.KEY || 'secret_fallback'`) were found in client-side code (`firebase.ts` and `SubscriptionPlans.tsx`).
**Learning:** Vite statically embeds `import.meta.env` values into the client-side bundle during the build process. If an environment variable is missing (or not prefixed with `VITE_`), Vite replaces the `import.meta.env` statement with `undefined`. Consequently, any inline fallback string provided via the logical OR operator (`||`) becomes the direct assigned value and is shipped unprotected within the minified frontend bundle, completely exposing the secret.
**Prevention:** Never use inline string fallbacks for sensitive keys when relying on `import.meta.env`. Strictly utilize explicit individual static access without fallbacks (e.g., `const apiKey = import.meta.env.VITE_API_KEY;`), and implement dedicated runtime validation checks to securely fail or throw errors if the required variables are missing.
