## 2026-07-04 - Hardcoded API Key Fallbacks\n**Vulnerability:** Found hardcoded fallback keys for Razorpay and Firebase configuration in the codebase.\n**Learning:** Relying on fallback default keys rather than strictly using environment variables can accidentally expose test or production credentials in the client bundle.\n**Prevention:** Ensure sensitive configuration values strictly use `import.meta.env` without providing hardcoded fallback string literals.
