## 2025-04-25 - Prevent Exposure of Hardcoded API Keys via Fallbacks
**Vulnerability:** Client-side source code contained hardcoded fallback values for sensitive API keys (`RAZORPAY_KEY` and `firebaseConfig`), meaning that if environment variables were accidentally missing, the application silently fell back to exposing real keys to the browser, potentially compromising backend services and user data.
**Learning:** Hardcoded fallbacks within the `|| 'value'` pattern bypass the environment configuration validation entirely. Because Vite statically embeds `import.meta.env` values or leaves them as expressions to be evaluated, the literal fallback strings are directly shipped in the minified frontend bundle, easily discoverable via developer tools or automated scans.
**Prevention:** Strictly enforce configuration via `import.meta.env` and throw explicit runtime errors if required security-sensitive variables are missing. Never commit fallback secrets into source control.
