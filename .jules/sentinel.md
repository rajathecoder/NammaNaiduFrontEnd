## 2024-06-22 - XSS via dangerouslySetInnerHTML\n**Vulnerability:** XSS vulnerability found in CMS pages where raw API content was passed directly into \`dangerouslySetInnerHTML\` without sanitization.\n**Learning:** In a Vite SPA, naive regex fallback for SSR logic is insecure. Rely on robust \`DOMPurify\` sanitization, ensuring early return when DOM is unavailable (`typeof window === \"undefined\"`).\n**Prevention:** Always wrap dynamically fetched HTML content in a wrapper utility (like \`sanitizeHTML\`) before rendering it with \`dangerouslySetInnerHTML\`. Never trust upstream API content blindly.
