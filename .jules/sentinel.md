## 2025-06-09 - XSS Vulnerability in CMS Rendering
**Vulnerability:** User-generated or admin-generated HTML content from the CMS was being rendered directly using `dangerouslySetInnerHTML` without any sanitization in `ContentPage.tsx`, `ContactUs.tsx`, and `CMSPage.tsx`. This poses a severe Cross-Site Scripting (XSS) risk if the CMS is compromised or content is maliciously injected.
**Learning:** React's built-in protections are bypassed when using `dangerouslySetInnerHTML`. In a Vite SPA, implementing DOM-based sanitizers like `dompurify` requires checking for the existence of the `window` object to safely support any future SSR environments. Simple Regex replacements are insufficient for HTML sanitization.
**Prevention:** Always wrap variables passed to `dangerouslySetInnerHTML` with a robust sanitization library like `DOMPurify`. Ensure the sanitization utility gracefully falls back (e.g., returning an empty string) if executed outside of a browser context (i.e. `typeof window === 'undefined'`).
