## 2024-04-11 - Fix N+1 queries for profile photos
**Learning:** Found an N+1 fetching anti-pattern in React components (`HomePage.tsx`, `useHomePageData.ts`) where a list API was immediately followed by iterating over the results to make separate individual detail API calls for images, even when the data `personPhoto` with `photo1link` was already part of the initial list response. This causes significant frontend rendering delays and strains backend resources unnecessarily.
**Action:** Always inspect the payload of list API endpoints (like `getOppositeGenderProfiles`) before introducing supplementary detail API calls (like `GET_PHOTOS`) to ensure the required data isn't already being delivered in the initial fetch. Leverage existing associations safely instead of redundant fetches.
