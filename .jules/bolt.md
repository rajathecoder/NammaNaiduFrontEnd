## 2025-01-01 - Avoid Redundant API Calls for Photos (N+1 Query Problem)\n**Learning:** The `getOppositeGenderProfiles` API returns user photo information nested inside the `personphoto` array. Making a separate API call for each profile's photo using the `/api/users/photos` endpoint causes an N+1 query problem, which severely impacts performance when loading profiles.\n**Action:** Extract the photo information directly from the nested `personphoto` array returned in the original `getOppositeGenderProfiles` payload instead of making redundant network requests.
