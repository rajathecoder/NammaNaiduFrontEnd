## 2025-10-25 - Avoid N+1 API Calls for Profile Photos\n**Learning:** The backend `getOppositeGenderProfiles` payload now includes `personPhoto` (or `personphoto`) data directly. Making separate N+1 calls to `/api/users/photos/${id}` for opposite-gender profile photos is unnecessary and causes performance bottlenecks on pages rendering multiple profiles.\n**Action:** Use the inline photo data (e.g., `profile.personphoto?.find(p => p.photoplacement === 1)?.photo1link` or similar) to extract the photo directly from the profile object instead of making separate API calls for each profile. Remove the N+1 photo fetching code in `HomePage.tsx` and `useHomePageData.ts`.
