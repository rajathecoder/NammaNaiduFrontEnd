## 2025-07-29 - Memoization of heavy array filtering operations in React
**Learning:** Found an opportunity to improve rendering performance on the Matches page. The `getFilteredProfiles` function was being executed on every render, filtering the `allMatches` array. For pages with a large number of profiles, this can be an expensive operation that blocks the main thread during rendering. Wrapping `MatchCard` with `React.memo` is another good optimization for large lists of profiles.
**Action:** Use `useMemo` for any complex filtering or mapping of large datasets to ensure it only recalculates when dependencies change (like filters or data source). Wrap frequently rendered child components in lists with `React.memo` to prevent re-renders unless props change. Memoizing event handlers passed to child components with `useCallback` also helps prevent unnecessary re-renders.
